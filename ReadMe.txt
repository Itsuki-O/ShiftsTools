概要：シフト作成アプリ

使い方：起動すると、１．新規作成ボタンと２．保存済みのスケジュールが表示されます。
　　　＜１．新規作成ボタンについて＞
　　　　　　新規作成ボタンを押すとスケジュールの新規作成画面が表示されます。
　　　　　　作りたいシフト表の名前（1~10文字）と作りたいシフトの年月（必須）を選択して決定を押すと最初の画面に戻ります。
　　　＜２．保存済みスケジュールについて＞
　　　　　　保存しているスケジュールについて編集ボタンと削除ボタンが用意されており、編集ボタンを押すと編集画面に移ります。

　　　＜編集画面について＞
　　　　編集画面に移るとシフト編集画面が表示され、
　　　　役職追加ボタン→勤務形態追加ボタン→スタッフ追加ボタンの順に登録することで、シフト表にスタッフを追加することができます。

　　　　・役職追加ボタン
　　　　　　新しい役職を追加します。文字数が1~6文字以内でそれ以外の文字数は警告アラートが表示されます。
　　　　・勤務形態追加ボタン
　　　　　　勤務形態（早番など）を登録します。文字は0~3文字以内で4文字以上の入力は3文字に切り取られます。
　　　　　　開始時間と終了時間は初期表示の通りに書き込まないと登録されません。
　　　　　　OKボタンを押すと編集画面の勤務形態一覧に新たに表示されます。
　　　　・スタッフ追加ボタン
　　　　　　スタッフを追加します。スタッフ名1文字以上、役職登録、週の希望勤務日数、雇用形態を選択し（すべて必須）追加します。
　　　　　　追加するとスタッフがシフト表に表示されるようになります。

　　　　・スタッフシフト編集
　　　　　　該当年月の日数が表示され、スタッフ行にある。コンボボックスから勤務形態を選択します（空白は実質休み）。
　　　　　　パートか正社員かで週に働ける時間の上限が定められています。
　　　　　　一週間でその合計時間を超えると登録できないと表示されるようになり、選択が取り消されます。
　　　　　　※早すぎると反映されないのでゆっくり押してください※
　　　　・完了して戻るボタン
　　　　　　データを保存し、最初の画面に戻ります。
　　　　・？ボタン
　　　　　　開くとヘルプ（ReadMe.txt）がメモ帳で表示されます。

備考：スタッフの雇用形態による継承が完璧ではない。
　　　希望日数を登録するが、使うまでに至っていない。
　　　スタッフを消せない。
